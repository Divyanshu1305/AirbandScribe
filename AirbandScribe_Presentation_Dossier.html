AirbandScribe

Aeronautical VHF Automatic Speech Recognition & Acoustic Signal Intelligence Workstation
Executive Summary for Presentation:
AirbandScribe is an end-to-end, domain-specialized Automatic Speech Recognition (ASR) system engineered specifically for Air Traffic Control (ATC) voice communications on VHF frequencies (118.000–136.975 MHz). It resolves the four core failure points of generic speech models in aviation: heavy carrier noise, rapid multi-speaker transmissions, long audio boundary loss, and domain-specific phraseology (runways, flight levels, vectors, and callsigns).

1. The Problem Space & Aviation Challenges

  • Acoustic RF Degradation: Aviation communications use legacy VHF Amplitude Modulation (AM), resulting in heavy static, ignition noise, heterodyne squeal, and background cockpit noise.
  • Domain Phraseology vs. Standard English: Commercial speech engines fail on aviation phonetics (e.g., "tree" for 3, "fife" for 5, "niner" for 9) and misinterpret operational clearances (e.g., transcribing "runway two seven left" as generic numbers rather than "Runway 27L").
  • Boundary Loss in Long Broadcasts: ATC recordings frequently span 10 minutes to several hours. Traditional single-pass inference runs out of memory or drops sentences across chunk seams.

3. Engineering Accomplishments: From Scratch to Advanced

A. Digital Signal Processing (DSP) Engine (`transcribe_atc.py`)

  • Butterworth Bandpass Filter: Implemented a 5th-order digital IIR bandpass filter (100 Hz – 8,000 Hz) using SciPy, eliminating sub-audible aircraft vibrations (<100Hz) and ultra-high frequency RF receiver hiss (>8kHz).
  • Spectral Gating Noise Subtraction: Integrated non-stationary spectral gating via noisereduce with a configurable suppression ratio (default 75%), isolating spoken transmissions from carrier noise.
  • Silero VAD v6.2: Integrated Silero Voice Activity Detection to isolate voice transmissions from dead air, preventing the model from hallucinating text during periods of radio silence.
  • Hardware Auto-Detection: Created an executable resolver that queries system architecture. If an NVIDIA CUDA GPU is unavailable, it automatically switches to Intel/AMD AVX2 SIMD CPU acceleration.

B. Overlapping Chunking & Stitching Algorithm (`audio_chunker.py`)

  • Sliding Windows: Implemented 30-second temporal windows with 5-second overlapping boundaries for recordings longer than 60 seconds.
  • Longest Common Subsequence (LCS) Deduplication: Built an overlap deduplicator (deduplicate_overlap_text) that compares trailing tokens of window N with leading tokens of window N+1, stripping duplicated words at boundary seams.

D. Backend Web API & Persistence (`app.py`, `database.py`)

  • FastAPI Framework: Asynchronous high-throughput server with CORS middleware.
  • SQLite Persistence: Automatically stores audio duration, speech duration, processing time, compute device (CPU/CUDA), audio paths, and structured JSON segment timestamps.
  • REST API Endpoints:
    • GET /api/status: Real-time system telemetry and hardware capabilities.
    • POST /transcribe: Multipart upload with custom DSP parameters.
    • GET /transcriptions: Paginated search with query keyword filtering.
    • GET /transcriptions/{id}: Full segment and metadata retrieval.
    • DELETE /transcriptions/{id}: Database and filesystem purge.

E. Bespoke Aerospace Avionics Console (`frontend/src/components/transcribe.jsx`)

  • Live Zulu Clock: Real-time Greenwich Mean Time reference (HH:MM:SSZ).
  • Interactive Canvas Waveform: HTML5 time-domain waveform with decibel amplitude peaks, transmission highlight blocks, and glowing playhead scrubber.
  • A/B Audio Switcher: Instant live toggle between Cleaned VHF (denoised) and Bandpass Raw audio streams.
  • Aviation Telemetry Strip Deck: Real-time extraction of Callsigns, Runways, Headings, Altitudes, and VHF Frequencies.
  • Flight Progress Strips: Synchronized playback strips with color-coded tokens for clearances, runways, altitudes, headings, and callsigns.
  • Multi-Format Flight Recorder Export Suite: One-click export to SubRip Subtitles (.srt), WebVTT (.vtt), ICAO Telemetry (.json), and Dispatch Text (.txt).
  • Keyboard Flight Deck Shortcuts: SPACE (Play/Pause), ←/→ (Seek ±3s), R (Replay transmission), D (A/B audio toggle), M (Mute).

4. Key Presentation Talking Points (Q&A Cheat Sheet)

  1. Why not just use OpenAI Whisper directly?
    Whisper trained on standard internet audio fails on radio static, drops phrases during long radio pauses, and writes numbers arbitrarily. AirbandScribe cleans the signal with DSP first, gates dead air with VAD, and post-processes through an ICAO aviation normalizer.
  2. How does AirbandScribe handle long 1-hour recordings?
    It uses a 30s sliding window with a 5s overlap. Boundary phrases are re-stitched and deduplicated using Longest Common Subsequence matching so no clearance is dropped.
  3. Can it run without a high-end GPU?
    Yes. The core engine dynamically binds to AVX2 SIMD CPU vector extensions, achieving real-time factors of ~0.2x speedup on consumer laptop processors.
